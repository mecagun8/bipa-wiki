# LLM Wiki Rules

## 구조
- sources/ : 원문 문서 보관 (읽기 전용)
- wiki/ : LLM이 작성하는 위키 페이지
- index.md : 전체 페이지 목록
- log.md : 작업 기록

## 인제스트 (새 문서 추가 시)
1. sources/ 에 문서 추가
2. 문서 읽고 핵심 내용 추출
3. wiki/ 에 마크다운 페이지 작성
4. 관련 기존 페이지 업데이트
5. index.md 에 새 페이지 추가
6. log.md 에 작업 기록

## 쿼리
- index.md 먼저 읽고 관련 페이지 탐색
- 답변은 wiki/ 페이지 인용 포함

## 린트 (주기적 점검)
- 페이지 간 모순 확인
- 고아 페이지 확인
- 누락된 교차 참조 확인
